# LELE — Dancer String Triggering Device

Automatic Ukelele Responding to Dancing for progressively plucking the strings of a mechanical music-box system.

<img width="9068" height="5200" alt="Frame 31" src="https://github.com/user-attachments/assets/39dc901d-4d34-4a04-bd68-e51f8a859e15" />



## System overview

LELE arranges four matching string modules around a shared platform. Each module combines a timber frame, a vertically driven string-contact carriage and a servo-operated pick. The repeated layout lets the modules be built and maintained separately before they are installed on the common base.

| Subsystem | Input | Mechanical action | Output |
|---|---|---|---|
| Linear carriage | 28BYJ-48 stepper motor | Rotates a T8 lead screw through a shaft coupling | Moves the string-contact carriage vertically |
| Strumming drive | SG90 servo motor | Swings a pick holder across the string | Plucks and releases the string |
| String system | Tuning machine and bridge hardware | Sets and holds string tension | Provides the playable string path |
| Structural frame | Laser-cut sheet and plywood | Locates shafts, motors and string hardware | Keeps each module aligned |

## Materials and components

<img width="9068" height="4032" alt="Frame 33" src="https://github.com/user-attachments/assets/b6819e85-83ef-4f46-9935-bc5d822e7968" />


| Component group | Material / specification | Role in the mechanism |
|---|---|---|
| Base platform | 4 mm laser-cut sheet | Supports the complete assembly and locates the upright modules |
| Frame and decks | 4 mm laser-cut plywood | Forms the spine, gussets and equipment decks |
| Custom fittings | FDM-printed polymer | Connects the drive and string hardware to the frame |
| Linear drive | 28BYJ-48 stepper motor and shaft coupling | Turns the lead screw to move the carriage vertically |
| Lead screw and nut | T8 lead screw and flanged brass nut | Converts screw rotation into vertical carriage travel |
| Shaft supports and fasteners | Bearings, screws, nuts and washers | Supports rotating parts and secures hardware to the frame |
| String and tuning | Ball-end guitar string, tuning machine and bridge hardware | Sets string tension and anchors the lower end |
| Strumming drive | SG90 servo motor and pick holder | Swings the pick across the string |
| Strumming pick | Purchased guitar pick | Contacts and releases the string during each sweep |
